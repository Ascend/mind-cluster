# auto_single_diag

## Command Function

Diagnoses a specified link. The device type (`host`/`switch`/`bmc`) is automatically identified based on the IP address, and the meaning of the port varies by device type.

- The tool reads the structured data in the cache directory, performs full diagnosis and root cause analysis, retains only the diagnosis result of the specified link (the local or peer end that matches the IP + port) in the result display phase, and generates a report.
- You need to run `auto_collect` first (which can be run multiple times in batches), and then run this command to start single-link diagnosis.

## Command Format

| Command Format | Description |
|---------|------|
| `auto_single_diag <ip> <id>` | Diagnoses a specified link |
| `auto_single_diag ?` | Views details |

## Parameter Description

| Parameter | Description                                                                                                         |
|------|------------------------------------------------------------------------------------------------------------|
| `ip` | Device IP address. `host`, `switch`, and `bmc` devices are supported                                                                               |
| `id` | Port ID. The meaning varies by device type:<ul><li>`host`: NPU port number (`npu_id`, value range 0 to 7)</li><li>`switch`: switch port name (for example, 400GE1/0/1:10)</li><li>`bmc`: NPU port number of the associated host (value range 0 to 7)</li></ul>|

## Prerequisites

Before running `auto_single_diag`, ensure that structured data exists in the cache directory (generated by collection through `auto_collect` or `auto_collect_diag`) and that the specified IP and port exist in the cached data.

## Output Description

- Success: `Single-link diagnosis complete. N faults are found in total. Only this link is displayed in the diagnosis result.`
- No fault is found: `Diagnosis complete for link <ip> port <id>. No fault is found.`
- Insufficient parameters: The usage `auto_single_diag <ip> <id>` is displayed.
- The device or port does not exist: A message indicating that the device IP is not found or the port ID does not exist is displayed, and the available ports are listed.
- Report generation failure: `Failed to generate the report. After the occupation is released, you can use ' auto_single_diag <ip> <id> ' to regenerate the report.`

## Examples

Non-interactive mode (command and output):

```bash
ascend-fd-tk set_conn_config /home/user/conn.ini auto_collect auto_single_diag 1.1.1.1 5
# Other log output...
Single-link diagnosis complete. 2 faults are found in total. Only this link is displayed in the diagnosis result.
```

Interactive mode (command and output):

```bash
ascend-fd-tk
>>> auto_single_diag 1.1.1.1 5
Single-link diagnosis complete. 2 faults are found in total. Only this link is displayed in the diagnosis result.
```

Diagnose the link of a switch port:

```bash
>>> auto_single_diag 1.1.1.3 400GE1/0/1:10
Single-link diagnosis complete. 1 faults are found in total. Only this link is displayed in the diagnosis result.
```
