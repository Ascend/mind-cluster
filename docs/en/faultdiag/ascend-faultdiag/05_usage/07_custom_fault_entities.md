# Custom Fault Entities

<!-- md-trans-meta sourceCommit=0bdfcd26262ca7cc1165bb55c8f28c6a29b377ef translatedAt=2026-08-24T02:27:36.898Z pushedAt=2026-08-24T02:51:43.248Z -->

This feature extends the diagnostic capabilities of ascend-fd, allowing you to define new fault entities through JSON files.

ascend-fd supports operations such as log parsing, fault diagnosis, and suppressing fault logs for custom fault entities.

To define custom fault entities, see [entity Command (Custom Fault Entities)](../06_api/05_command_entity.md).
