# Fault Log Masking

<!-- md-trans-meta sourceCommit=8c36d230fe88892740f2c741498130e6a9bb3cce translatedAt=2026-08-24T02:27:46.283Z pushedAt=2026-08-24T02:51:43.254Z -->

The fault log masking feature is used to filter out fault log information containing specified keywords during log parsing, so that it is not recorded in the parsed file.

To use the fault log masking feature, see [blacklist Command (Fault Log Masking)](../06_api/06_command_blacklist.md).
