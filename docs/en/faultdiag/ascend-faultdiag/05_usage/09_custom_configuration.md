# Custom Configuration File

With a custom configuration file, you can configure parameters for parsing fault logs as needed, such as log size limits, enabling/disabling parsing modules, and custom file parsing rules.

To use a custom configuration file, see [config Command (Custom Configuration)](../06_api/07_command_config.md).
