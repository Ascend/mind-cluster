# version Command (Display Version Information)

## Function

Displays the version information of ascend-fd.

## Command Format

```shell
ascend-fd version [-h]
```

## Parameter Description

| Parameter       | Type | Mandatory | Description        |
|------------|------|-----------|--------------------|
| `-h`, `--help` | -    | No        | Display help info. |

## Usage Examples

```shell
ascend-fd version
```

Example output:

```text
ascend-fd v26.2.0
```
