# version Command (Display Version Information)

<!-- md-trans-meta sourceCommit=8c36d230fe88892740f2c741498130e6a9bb3cce translatedAt=2026-08-24T02:29:31.272Z pushedAt=2026-08-24T02:51:43.292Z -->

## Function

Displays the version information of ascend-fd.

## Command Format

```shell
ascend-fd version [-h]
```

## Parameter Description

| Parameter       | Type | Mandatory | Description        |
|------------|------|-----------|--------------------|
| `-h`, `--help` | -    | No        | Display help info. |

## Usage Examples

```shell
ascend-fd version
```

Example output:

```text
ascend-fd v26.1.0
```
