# Installation Using a Tool<a name="ZH-CN_TOPIC_0000002479386368"></a>

With Ascend Deployer, you can install cluster scheduling components in batches, significantly reducing the complex configuration operations involved in manual installation and streamlining the installation process. It is suitable for batch component installation in cluster scenarios.

**Key Steps for Tool Installation**

1. Verify that the hardware product and OS are supported in the Ascend Deployer support list.
2. Deploy Ascend Deployer, ensuring that the tool version matches the cluster scheduling component version.
3. Follow Ascend Deployer guide to configure installation parameters and execute batch component installation. Steps include:
   - Remote server connection (optional)
   - Configuring server installation and deployment parameters
   - Executing installation commands
   - Checking installation results
   - Configuring environment variables

For the list of hardware products, operating systems, and installation scenarios currently supported by Ascend Deployer, see [Supported Products and OSs](https://gitcode.com/Ascend/ascend-deployer/blob/branch_v26.1.0/docs/en/01_introduction/02_supported_product_and_os.md) in *MindCluster Ascend Deployer User Guide*, to determine whether to use Ascend Deployer.

To use Ascend Deployer, see [Installing Ascend Software](https://gitcode.com/Ascend/ascend-deployer/blob/branch_v26.1.0/docs/en/05_installation_and_upgrade/02_install_softwares.md) in *MindCluster Ascend Deployer User Guide*.

>[!NOTE]
>
>- It is recommended that users first review the usage constraints and startup parameters of the corresponding components in [Manual Installation](./01_manual_installation.md) before using the tool. This will help users better understand the usage scenarios and functionalities of the components.
>- The tool version must match the version of the cluster scheduling components. Versions cannot be mixed.
