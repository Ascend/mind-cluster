# 使用WebUI对话式运维<a name="ZH-CN_TOPIC_00000026faultdiagnosis08"></a>

集群运维Agent自带一个对话式WebUI（Web User Interface，网页用户界面），浏览器打开即可用，无需安装任何前端依赖。在页面输入框里用一句话描述要查什么（例如「worker-1上有哪些故障卡」「train-77任务现在什么状态」），配置了大模型后，Agent会自行调用工具并流式给出结论；未配置大模型时页面会提示先配置模型，不影响其它功能。

## 打开页面<a name="sectionwebuiaccess"></a>

浏览器访问（端口以部署清单为准，默认9700；对外经Service `agent-core-ui`的NodePort 30443暴露）：

```shell
http://<节点IP>:30443/ui/
```

页面为「新建会话按钮 + 对话区 + 底部输入框」布局。点「＋ 新建会话」开始新话题；在输入框输入问题后点击「发送」或按Enter（Shift+Enter换行）。会话保存在组件进程内：重启组件或刷新页面后上下文丢失，需要留存的结论请自行复制。

## 配置大模型<a name="sectionwebuillm"></a>

对话能力依赖大模型，通过以下命令配置（仅支持OpenAI兼容接口格式的大模型服务，配置实时生效、无需重启组件）：

```shell
kubectl clusterops --create-llm-config
```

详细参数、环境变量方式与注意事项见[配置和清除LLM](./04_configuring_llm.md)。配置成功后页面左下角状态角标显示「LLM: 就绪」，即可开始对话。

## 对话中的工具调用<a name="sectionwebuitoolcard"></a>

Agent回答问题时会调用后台工具（故障设备、隔离设备、集群资源、任务状态、诊断），每次调用在回答上方以一张可折叠的工具卡展示：折叠时显示工具名、状态与耗时；展开可看状态/工具/请求号标签与完整返回内容（工具返回的原始JSON，按两空格缩进展示；技能正文等非JSON内容原样展示），也可复制返回结果。

未配置大模型时页面提示「未配置大模型，对话不可用；请配置模型后使用」，按上文配置后下一条消息即恢复对话。如需不需模型的确定性查询，可使用 kubectl 命令行直接查询集群与任务状态。

## 限制与建议<a name="sectionwebuilimits"></a>

- **单个会话不宜过长，并发会话不宜过多**：每轮对话都会把该会话的完整历史发给大模型，轮数越多回答越慢、消耗的模型额度越多。单个会话建议不超过20轮，超过后点「＋ 新建会话」另起话题。并发会话不建议超过4个。
- **同一任务的诊断同时只跑一次**：会话数本身几乎不占用服务端资源；对同一个任务（命名空间+任务名）重复发起诊断时，后发起的请求不会重新执行，回答里会说明「任务正在诊断中」，稍后再问即可。不同任务之间可以并行诊断。
- **一轮对话最长30分钟**：一轮指从点「发送」到收到完整回答的全过程，模型的全部推理步骤和中间的工具调用都算在这一轮里。超过30分钟本轮自动结束，页面提示「本轮处理超时」，请缩小问题范围后重试。
- **单次故障诊断最长20分钟**：故障诊断需要逐节点采集数据，是对话中最耗时的工具调用（一轮对话里可能调用多次）。某一次诊断超过20分钟，该次诊断按「调用超过时限被中止」处理，本轮不会中断，大模型会基于已获得的信息继续回答；需要完整诊断结论时，建议改用 kubectl 命令行执行诊断。
- **工具返回过长时会被截断**：单次工具结果上限9000字符，超出部分不带入上下文，返回末尾会有一句「已截断」说明，大模型会据此声明数据不完整。需要完整数据时请缩小查询范围（如指定节点）或改用 kubectl 命令行。
- **大模型服务不可达或被限流时**：页面提示「模型服务不可用」，本轮回答中断；工具查询与kubectl命令行不受影响，可稍后重试。
