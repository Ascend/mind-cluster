# auto_single_diag

## 命令功能

指定单条链路进行诊断，IP自动识别设备类型（host/switch/bmc），端口含义随设备类型不同。

- 工具读取缓存目录中的结构化数据，执行全量诊断与根因分析，在结果展示阶段仅保留指定链路（本端或对端命中IP+端口）的诊断结果，并生成报告。
- 需先通过 `auto_collect`（可多次分批执行），再执行本命令启动单链路诊断。

## 命令格式

| 命令格式 | 描述 |
|---------|------|
| `auto_single_diag <ip> <id>` | 指定单条链路进行诊断 |
| `auto_single_diag ?` | 查看详情 |

## 参数说明

| 参数 | 说明                                                                                                         |
|------|------------------------------------------------------------------------------------------------------------|
| ip | 设备IP地址，支持host、switch、bmc三类设备                                                                               |
| id | 端口id，含义随设备类型不同：<br>- host：NPU端口号（npu_id，取值0~7）<br>- switch：交换机端口名（如400GE1/0/1:10）<br>- bmc：关联主机的NPU端口号（0~7） |

## 执行前提

执行 `auto_single_diag` 前需确保缓存目录中存在结构化数据（通过 `auto_collect` 或 `auto_collect_diag` 采集生成），且指定的IP与端口在缓存数据中存在。

## 输出说明

- 成功：`单链路诊断完成，共发现 N 条故障，诊断结果仅展示该链路`
- 未发现故障：`链路 <ip> 端口 <id> 诊断完成，未发现故障`
- 参数不足：提示用法 `auto_single_diag <ip> <id>`
- 设备或端口不存在：提示未找到设备IP或端口id不存在，并列出可用端口
- 报告生成失败：`生成报告失败，解除占用后，可使用 ' auto_single_diag <ip> <id> ' 重新生成报告。`

## 示例

非交互式方式（展示命令与回显）：

```bash
ascend-fd-tk set_conn_config /home/user/conn.ini auto_collect auto_single_diag 1.1.1.1 5
# 其他日志输出...
单链路诊断完成，共发现 2 条故障，诊断结果仅展示该链路
```

交互式方式（展示命令与回显）：

```bash
ascend-fd-tk
>>> auto_single_diag 1.1.1.1 5
单链路诊断完成，共发现 2 条故障，诊断结果仅展示该链路
```

诊断交换机端口链路：

```bash
>>> auto_single_diag 1.1.1.3 400GE1/0/1:10
单链路诊断完成，共发现 1 条故障，诊断结果仅展示该链路
```
